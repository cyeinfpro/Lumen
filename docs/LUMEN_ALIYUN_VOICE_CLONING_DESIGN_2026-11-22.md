# Lumen 声音工作台：阿里百炼音色克隆与配音

日期：2026-11-22 · 状态：后台配置后自动启用；远端灰度验收独立进行 · 首版上游：阿里云百炼 `qwen-audio-3.1-tts-plus`

## 1. 目标和边界

用户提供本人或明确授权的一小段录音，试听后保存一个私有音色。以后只需要选音色、粘贴文稿，就能拿到可剪辑的 WAV。关掉页面不丢任务，长稿读错一句能只重做所在段，不需要重新整篇生成。首版只做中文旁白优先的单人克隆和合成；不做公开音色市场、未授权模仿、实时对话、多角色混音、语音变声、模型切换或自动换地域。

基线来自 Lumen GitHub main 的 README、AGENTS、MEMORY 和 UI 规范：Next.js / FastAPI / arq、PostgreSQL + Redis；现有视频流程已有任务恢复、计费冻结/结算、资源入库。实现前对照目标 checkout 的实际文件；以下目录是落点而非已存在的接口。不要加第二套任务平台，也不要借图片代理把参考声音公开化。

## 2. 用户流程

- 左侧新增「声音」，打开先看最近任务和「我的音色」；桌面可左右并排，手机单列。上传支持拖拽 WAV/MP3/M4A；就地显示长度、音频质量和可裁剪范围，选段后直接回放。上传前说明：仅允许本人或获得明确授权的声音，选段会送到阿里百炼；原录音与音色不公开。本人和授权人分别留确认记录，仅登录用户可用；启用后仍按滥用风险限速，并保留后台移除 Key 的停用入口。
- 本地分析只做可解释的质量检查，不识别人是谁，也不加一轮 LLM：读取时长/通道/采样率、静音、削波及噪声提示。重叠人声/音乐不能可靠判定时显示「请确认只有一个人在说话」，不要显示虚假的「校验通过」。允许上传整个采访文件的需求不在首版，建议先导出干声。上游推荐 10–20 秒、最长 60 秒、≤10 MB、≥16 kHz；Lumen 默认引导 10–20 秒，把已裁剪有效片段转单声道 PCM16 WAV，双声道先试听选主声道，不盲目混合。仅硬拒文件不可解码或违反硬限制，质量风险给用户重录提示。
- 克隆进度从「检查录音 → 正在创建音色 → 可以试听」；用一条与样本不同的短文本试听。试听完成可命名并保存；未满意可重新选段创建草稿，不覆盖已有稳定音色。试听走真实 TTS，界面不把「建音色免费」误写成「试听免费」。
- 「制作配音」：选已就绪音色、粘贴文本、显示预估费用、点生成。首版高级设置仅留语速与简短的语气指令（经接口实测支持再启用）；不同段落显示生成/失败状态，能重做指定段。结果可播放及下载 WAV，不把未齐的段落当成成片；播放就地展开，不用多层弹窗。支持键盘和屏幕阅读器，使用现有语义主题变量、移动端 safe-area 工具类（见 [UI 规范](frontend-theme-dialog-standards.md)）。

## 3. 阿里合同与适配

使用独立 `AliyunSpeechClient`，不让前端传入任意上游 URL 或 API Key。配置由管理员注入 `region`（默认北京）、`workspace_id` 与服务密钥引用；北京/新加坡按官方域名白名单构造 Workspace endpoint，且同音色绑定 provider + 地域 + workspace + target model。配置变更/密钥轮换不得静默迁移旧音色；旧地域与凭据仅按明确的数据迁移/删除流程处理。

| 动作 | 上游行为 |
| --- | --- |
| 注册 | POST `/api/v1/services/audio/tts/customization`，外层 `model=voice-enrollment`，`input.action=create_voice`、`target_model=qwen-audio-3.1-tts-plus`、`prefix`（随机 ASCII 字母数字、最多 10 位且本地唯一）、`audio` 为裁剪后的 WAV Data URI。只发这段录音，不发原始长录音、公有链接、用户真实姓名。 |
| 查询 | 同一地址 `query_voice`，对应 `voice_id`；以 `OK` 进入试听，`DEPLOYING` 有界退避；上游实际错误/未知状态不能当作 ready。遇创建结果不明时用 `list_voice` 分页精确匹配已持久化的唯一前缀，仍不明不重发。 |
| 合成 | POST `/api/v1/services/audio/tts/SpeechSynthesizer`，`model` 使用绑定型号、`input.voice` 用已保存 ID、`format=wav`，统一请求 `sample_rate=24000`，同批段参数固定。首版走非流式以减少重复通路；本地异步任务不依赖上游异步。保存 `request_id`、`usage.characters`，完成响应包含临时 `output.audio.url`。 |
| 撤销 | 先阻断本地使用和排队任务，再由后台 `delete_voice`；确认后标已删。上游未确认则保留待清理状态并做受控重试，不能向用户宣称远端已删。 |

使用短时限、验证 TLS；音频下载只走适配器，限制官方输出域、重定向（默认禁用）、地址范围、字节数和实际解码格式，不转发认证头，不把临时链接暴露浏览器。官方成品 URL 有效 24 小时，Worker 在签发后立即拉取并校验；只对已有合法链接重试下载，不重跑已成功的计费合成。版本放行前以使用自有或已授权样本的测试租户核对 endpoint、限额、WAV 实际格式、错误码和计费；本文没有进行真实调用。

## 4. 接入 Lumen 的 API / 数据 / 任务

- `apps/api`：沿用现有登录与资源 owner 校验。建议 API：`POST /voices`（接已上传私有样本 ID、裁剪区间及同意记录）、`GET /voices`、`POST /voices/{id}/preview`、`PATCH /voices/{id}`（仅名称/保存）、`DELETE /voices/{id}`；`POST /speech/jobs`、`GET /speech/jobs/{id}`、`POST /speech/jobs/{id}/segments/{n}/retry`、私有下载。具体统一到现有 API 前缀和错误格式；返回 Lumen ID/进度，不返回密钥、前缀或上游音色 ID。每个 owner 校验覆盖源资产、音色版本、任务、段落和下载，跨用户一律不可见。
- `packages/core` + Alembic：`voice_profiles` 存 owner、状态、同意记录引用、上游绑定和撤销时间；`speech_jobs` 存用户任务、输入预算、音色版本、参数快照；`speech_segments` 按 job/序号/修订唯一，记录输入范围、上游请求状态、临时结果恢复信息、产物和用量。沿用现有任务关联和资产系统，不复制钱包与用户。源文件和成品分别用私有存储类别；参考片段 Draft 默认保留至多 24 小时（成功并完成试听后可删除），成品按账户当前资产生命周期保留；原文件不因克隆任务删除。被撤销音色不能续跑或再次试听，已生成成品不悄悄删除，导出/撤销范围在界面明确说明。
- `apps/worker`：借现有 arq、租约、恢复 worker 和任务 SSE。创建 DB 记录后可靠入队（沿用项目现有机制或由 reconciler 补投）；刷新用任务快照补齐事件。音色、整稿与段落分别有幂等键，校验请求内容摘要；变更参数才算新操作。短句默认一次完成；长文本按段落/标点切分，不拆英文单词、数字和缩写；产品先用每段约 200–400 计费字符的保守目标，真实上限以接口验收为准。固定段序，解码后拼接 PCM，统一采样率/声道和 WAV 头，避免拼接处被剪掉字。段落重做生成新修订并原子替换成品；旧成品保留到新版就绪。
- 发请求前持久化尝试和租约。确定未送出可重试，明确 429 尊重退避；超时/断连若可能已经受理，记为「结果待确认」，不自动重发，不声称「未扣费」。已知上游成功但下载失败时恢复下载；文件验证和持久化完成后才发布成功。采用现有计费冻结/结算/释放机制（避免与外部账单混淆），按段核对上游用量，只重做失败或用户指定的段。限制每账号创建频率、短预览、并发和每日文字额度，使音频不抢图像／视频队列。
- 报价按百炼中国站官方当前价格：Qwen-Audio-TTS 注册免费；北京 ¥1.40 / 万计费字符，新加坡 ¥2.19 / 万；汉字 2，常见其他字符 1，不另收输出费；3,000 个纯汉字约 ¥0.84/¥1.31，重生成另计。前端只展示服务端估算与使用币种，结算对账以 `usage.characters` 和对应价表为准，不把试用额度计入默认成本。日志只放标签化错误、计费字符、耗时与请求 ID，不落参考音频、全文、授权凭据或完整临时链接。

## 5. 隐私及故障收口

私有音色、参考录音、过程试听不进入公共分享；文件响应独立做 owner 校验。首版不允许共享音色、不开放任意 URL 上传、不生成以他人名义欺骗的样本。合成请求使用服务支持的 AIGC 标记，且拼接后检查标记是否保留；若服务标记无法跨拼接保留，整稿增加可验证导出标记并在产品中明确标注 AI 合成，不声称已保留原有标记。撤销流程需清理远端音色、未完成临时文件和待分发产物，注明不能召回已下载的副本。加入可由管理员关闭的入口和上游拒绝启用开关；关闭只阻断新请求与排空，不删除历史文件。灰度仅允许已核对授权的测试账号，记录创建成功率、试听耗时、音色待确认数、长文分段失败率、重复发送次数和费用偏差；达到超时与错误阈值暂停新任务，不静默切换上游。

## 6. 实施顺序与验收

1. **后端基础**：迁移、feature flag 默认关、适配器、私有录音检查与注册状态。用假上游夹具跑注册正常/拒绝/超时/重复、查询和撤销；零真实付费。
2. **合成闭环**：短试听、正文长度与字符预算、长文分段、产物入库与任务恢复。模拟 429、远端成功但下载失败、worker 重启、链接过期、队列重复投递、撤销与生成竞争、全段完成前不发布成片、重试单段不重跑整篇。做 owner/恶意 URL/解码限额测试。
3. **工作台**：对照 Lumen 的主题与移动端规范；验证上传失败、裁剪回放、关闭/刷新恢复、段落重试、键盘和手机 WAV 下载。代码阶段运行 `git diff --check`，前端运行 type-check/lint/build，后端有对应单元、API 与 worker 集成测试。
4. **灰度验收**：明确授权后做真实接口验证，用相同参考录音比较 3 类稿（纪录片、宣传片、中英混读），至少 3 个已授权声线；人工检查像不像本人、专名、停顿、段落漂移、长稿接缝。验收以可听的 WAV、请求与账单对账、撤销结果为准，不以 demo 或任务成功码替代。只在另外授权发布时走项目正式 release 流程。

## 7. 工作区首版实施与上线门槛

- 入口为 `/voice`，桌面和移动导航按当前登录用户的能力接口判断。Web 使用现有登录、请求身份校验和 CSRF 请求头。当前任务恢复使用有界轮询和持久化任务快照，未接入全局 SSE 任务托盘。
- 录音会按所选声道做私有裁剪并转 16 kHz 单声道 PCM16；试听和成片请求 24 kHz WAV。音色注册显式设置 `max_prompt_audio_length=20`，防止上游默认裁到 10 秒。未保存的过期音色后台撤销上游音色，避免长期占用共享额度。
- 升级后先应用声音任务迁移。管理员从「后台 → 运行与审计 → 供应商 → 声音 · 阿里云百炼」填按量付费的百炼 Key 并保存。默认北京，不再设置声音专用环境变量或逐个加白名单。可选填写同地域业务空间 ID，切换到官方业务空间域名；留空使用对应地域的 DashScope 原生域名。没有 Key 时不准入新付费任务。后台保存后自动等待 Worker 读取该版本，再为已登录用户开启声音，不需要手工重启服务。
- 后台只显示是否已配置及 Worker 状态，Key 用项目已具备的加密配置保护，不回显。密钥替换时重新等待同一配置版本就绪；卸载或更换地域/工作空间不会让旧音色静默跑到新空间，历史成品仍按权限访问。管理页确认的是 Worker 收到配置，不是替用户发一条计费请求验证阿里权限。新版本只发版，不替用户填写 Key。
- 以段为单位锁定价格并留存冻结/结算记录；结果未知的段不会自动重新提交或释放其预留，管理员上线前需准备人工对照百炼请求与账单的流程。首版不开放语气指令，直至用授权素材验证真实效果。
- 离线模拟和合成夹具不能证明真实阿里调用、生产 PostgreSQL 迁移、音色相似度或线上听感；这几项需要在受控灰度验收，不应在未验收时开启生产功能。

## 8. 深度复核：恢复、读路径与工作台

这轮覆盖音色上传和声道、上游注册/合成与音频下载、段落冻结/结算/重做、最近记录及账号切换。改的是工作区，未对接真实租户，也未修改生产功能开关。

| 优先级 | 已证实的问题 | 工作区修复 |
| --- | --- | --- |
| P1 | 已知合成成功的回执原本和结算同事务；钱包或数据库短暂故障会一起回滚，重启只能按未知结果处理。 | Worker 先持久化受租约保护的上游回执，再走幂等本地结算；回执已有时恢复不再次调用付费合成。原本就不确定是否送达的请求仍不盲重发。 |
| P1 | API 重做和 Worker 完成以相反顺序锁定音色及配音任务，PostgreSQL 上有互相等待的路径。 | 统一先锁任务再锁音色，不重复查询同一任务。 |
| P1 | 未知 HTTP 接受状态或异常响应结构有可能被当成确定拒绝，误释放预留。 | 上游适配器把非预期成功码、重定向、冲突和无法可靠解释的付费回执按不确定处理。只对已知成功的音频下载尝试连接恢复，不重放生成。 |
| P2 | 音色/任务列表每行再查一次库；多次段落重做时会把所有旧修订读到 API 进程。 | 音色与最近可播试听同一次数据库往返；有数据时历史任务及最新段落修订两次往返，保留访问范围与顺序。 |
| P2 | 长音频拼接先缓存完整 PCM；仅一段也会重封装，损失原容器的附加信息。靠后裁剪会做多余解码。 | 拼接按块读写 PCM，单段保留已验证的原上游容器；调整 FFmpeg 的定位方式并用靠后真实信号测试。多段重新封装不声称保留上游水印。 |
| P2 | 页面异步返回可能覆盖用户继续输入的稿件，直接打开路由和切换登录会话时状态不一致；读取失败会被误展示为空。 | 只清理已提交且未变的稿件，按当前登录会话隔离读写，读失败显式显示；裁剪/声道修改须重新确认所选片段，控件不被长列表淹没。 |

验收范围：45 项定向测试通过（Mock 上游 12、真实 FFmpeg 合成波形 10、Worker 15、API 5、前端 3）；7 个声音相关 TS/TSX 文件通过语法解析。前端定向类型检查与 ESLint 触及时间上限，未判为通过；未重跑全量生产构建或浏览器完整流程。API 实库查询用 SQLite 夹具，锁顺序回归不等同于真实 PostgreSQL 并发验收。

可定位到 `apps/api/app/routes/voice.py` 的段落批量读取、音色列表、任务列表及 `retry`，对应 `apps/api/tests/test_voice_routes_contract.py` 的 SQL 次数及加锁顺序回归；账务恢复、PCM 分块、上游与裁剪则由对应 Worker、适配器及输入测试覆盖。

仍需上线前验证：用授权声音完成真实接口/计费/听感验证；四处相关的灰度边界（API、Worker、钱包、私有存储）在实际 PostgreSQL 压力下验证；多段 WAV 的可验证 AIGC 标记；样本文件已落盘但数据库提交结果未知时的归属核对与安全回收。不要因数据库故障立即删除文件，也不要对无法核实的临时文件执行全量扫描删除。未授权开启功能或部署。
