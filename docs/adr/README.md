# Architecture Decision Records

Accepted Agent decisions:

- [ADR 0001](0001-agent-runtime-pi-provider-boundary.md): Pi session,
  provider transport, proxy, recovery, and billing boundary.
- [ADR 0002](0002-agent-credential-capability-envelope.md): ephemeral
  credential and tool capability envelopes.
- [ADR 0003](0003-agent-deployment-release-compatibility.md): always-running
  Runtime, conditional readiness, five-image releases, and transition behavior.
- [ADR 0004](0004-agent-verification-gates.md): deterministic versus live
  evidence, Provider/proxy matrix, full-stack controller, and rollout gates.

ADRs describe durable production constraints. The integration plan remains the
implementation roadmap and is not rewritten when a decision is accepted.
